}

Accessibility

  • Wrap it in <nav aria-label="Main"> inside the page <header> so screen readers list it as a landmark.
  • Mark the current page with aria-current="page"; the orange underline shows the same thing visually.
  • The hamburger is a real <button> with aria-label="Open menu", aria-controls and aria-expanded that flips between true and false.
  • All links and the hamburger are reachable with Tab and open with Enter or Space. Focus shows a 2px Warm Orange ring (9.4:1 on Navbar Dark).
  • White on Navbar Dark is 18.8:1, well above the 4.5:1 minimum.
  • Tap targets are at least 44 × 44px (each link is 60px tall).
  • Add a "Skip to main content" link before the navbar so keyboard users can jump past it.

.ds-overview-table tbody td {
  font: 400 var(--fs-p) var(--font-body);
  border-top: 1px solid var(--color-light-grey);
}

Accessibility

  • Build it as a real <table> with <th scope="col"> headings so screen readers announce the heading with each value.
  • Name the table with aria-label="Project overview", or a visible <caption>. Avoid a visually hidden caption inside a scrolling wrapper; it can clip the table border.
  • Dark Orange text on White is 4.6:1, which passes WCAG AA for text at any size. It was darkened from the original #F29100 (2.4:1) for this reason, so don't swap the old value back in.
  • On phones, let the table scroll sideways inside its own container rather than squashing the columns, or stack it into label and value pairs.
  • The Light Grey border is decorative; the headings carry the structure, so the 2.8:1 border contrast is acceptable.

  background: var(--color-warm-orange-30); /* #EDAA46 at 30% = #FAE6C8 */
  color: var(--color-black);
  font: 600 var(--fs-chart) var(--font-heading);
  padding: var(--space-10);
  border-radius: var(--radius-lg);
  position: relative; z-index: 1;
}
.ds-tldr__body {
  margin-top: -11px;                      /* Figma gap: -11px */
  padding: calc(var(--space-10) + 11px) var(--space-10) var(--space-10);
  border: none;
  border-radius: 0 0 var(--radius-lg) var(--radius-lg);
  background: var(--color-warm-orange-30);
}

Accessibility

  • Make each box a <section> labeled by its title (aria-labelledby), and use a real heading for the title at the right level for the page.
  • Black on the 30% Warm Orange fill is 17.2:1. Don't use white text on it.
  • The 30% fill is flattened onto White as #FAE6C8, so the 11px area where the title overlaps the body doesn't get darker. Only place the box on a White background.
  • Keep each box to one or two short sentences. Don't put the only copy of important information in the TL;DR; repeat it in the body.
  • Use a grid that stacks to one column on phones so text never gets squeezed.
  • Don't set a fixed height; let the box grow when text is enlarged or zoomed to 200%.

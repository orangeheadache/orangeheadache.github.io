Foundations

Typographical hierarchy

Quicksand for headings and Oxygen for navigation and body text, on a Major Third scale (ratio 1.25) from a 16px base.

Typefaces

Quicksand

Headings, chart headings. Weights 400, 600, 700. var(--font-heading)

Oxygen

Navigation, Heading Five and paragraph text. Weight 400. var(--font-body)

Major Third scale

Every size comes from one ratio. The base is 16px, which is 1rem, and each step up multiplies by 1.25 (a Major Third). The same scale is used across the whole site.

Accessibility

  • Use heading levels in order (one H1 per page, no skipped levels). Pick the level for structure, then style it if needed.
  • Sizes are in rem, so text follows the reader's browser font size setting and survives 200% zoom.
  • Body text is 16px. Keep the Small step for short captions and labels, never for paragraphs.
  • Keep lines near 65 characters; the 632px content column does this at 16px.
  • Don't use Light Grey (#999999) for text: it reaches only 2.8:1 on white.

CSS

/* Major Third: 1rem = 16px, ratio 1.25 */
--fs-small: 0.8rem;    /* 12.8px */
--fs-p:     1rem;      /* 16px */
--fs-h6:    1.25rem;   /* 20px */
--fs-h5:    1.563rem;  /* 25px, also --fs-chart */
--fs-nav:   1.25rem;   /* 20px, same step as h6 */
--fs-h4:    1.953rem;  /* 31.25px */
--fs-h3:    2.441rem;  /* 39.06px */
--fs-h2:    3.052rem;  /* 48.83px */
--fs-h1:    3.815rem;  /* 61.04px */

h1 { font: 700 var(--fs-h1)/1.25 var(--font-heading); }
h2 { font: 700 var(--fs-h2)/1.25 var(--font-heading); }
h3 { font: 600 var(--fs-h3)/1.25 var(--font-heading); }
h4 { font: 600 var(--fs-h4)/1.25 var(--font-heading); }
h5 { font: 400 var(--fs-h5)/1.3 var(--font-body); }
.nav-link { font: 400 var(--fs-nav)/1.3 var(--font-body); }
.chart-heading { font: 600 var(--fs-chart)/1.3 var(--font-heading); }
h6 { font: 400 var(--fs-h6)/1.3 var(--font-heading); }
p  { font: 400 var(--fs-p)/1.6 var(--font-body); }
